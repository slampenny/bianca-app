# Confluence Import Instructions - Cross-Border Data Transfers

## Quick Copy-Paste Instructions

1. Open the file: `packages/backend/docs/CROSS_BORDER_DATA_TRANSFERS.md`
2. Copy the entire contents
3. Go to your Confluence space where privacy policy documents are stored
4. Create a new page or edit existing page
5. Paste the content
6. Confluence will automatically convert the markdown formatting

## Manual Formatting Tips

If Confluence doesn't auto-format the markdown, you may need to:

### Headers
- `# Title` → Use Confluence heading styles (H1, H2, H3)
- The document uses H1 for main title, H2 for major sections, H3 for subsections

### Lists
- Bullet points (`-` or `*`) should convert automatically
- Numbered lists should convert automatically

### Checkmarks
- `✅` symbols may need to be replaced with Confluence checkboxes or checkmark emojis
- Or use Confluence's checkbox macro

### Tables
- The document doesn't use tables, but if you add any, use Confluence's table macro

### Code Blocks
- Code blocks (```) should convert to Confluence code blocks
- Or use Confluence's code macro
